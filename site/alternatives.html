A free, open-source alternative to Jam, Marker.io, BugHerd and Bird Eats Bug

QA-Wrap is a free bug report extension for QA testers. Here is how it compares with four hosted bug reporting tools, so you can pick the one that fits your team.

The short answer

  • Pick QA-Wrap when the recording has to stay on the tester’s machine, when you want no account, or when you want to read and change the code.
  • Pick Jam or Bird Eats Bug when your team wants hosted share links anyone can open.
  • Pick Marker.io or BugHerd when you collect website feedback from clients.

What the table cannot show

  • Every failure is linked to the action just before it, so the report says which click broke the page.
  • The report is written for you: title, steps to reproduce, what happened and the evidence.
  • File to Jira opens one dialog that lists what is sent and what is not.
  • The interface and the reports come in English and Arabic, right to left where Arabic needs it.
  • qa-wrap-bridge, a read-only MCP bridge, lets a coding agent read the sessions you recorded.

Where QA-Wrap is weaker

  • There are no hosted share links. You hand the report over, or send it to Jira, a tracker or a webhook.
  • It is not in the Chrome Web Store. Chrome and Edge install from the release zip with Developer mode, about 3 minutes, once. Firefox users install it from Firefox Add-ons.
  • One person makes it: Nader Alzghoul, a QA automation engineer in Amman, Jordan.

بديل مجاني ومفتوح المصدر عن Jam وMarker.io وBugHerd وBird Eats Bug

QA-Wrap إضافة متصفح مجانية لكتابة تقارير الأخطاء، صُنعت لمختبري الجودة. هنا مقارنتها بأربع أدوات مستضافة للإبلاغ عن الأخطاء، لتختار ما يناسب فريقك.

الجواب المختصر

  • اختر QA-Wrap حين يجب أن يبقى التسجيل على جهاز المختبِر، أو حين لا تريد حسابا، أو حين تريد قراءة الشيفرة وتعديلها.
  • اختر Jam أو Bird Eats Bug حين يريد فريقك روابط مشاركة مستضافة يفتحها أي شخص.
  • اختر Marker.io أو BugHerd حين تجمع ملاحظات العملاء على المواقع.

ما لا يظهره الجدول

  • كل عطل مربوط بالإجراء الذي سبقه مباشرة، فيقول التقرير أي نقرة كسرت الصفحة.
  • يُكتب التقرير لك: العنوان، وخطوات إعادة الإنتاج، وما حدث، والدليل.
  • زر الإرسال إلى Jira يفتح نافذة واحدة تعرض ما سيُرسل وما لن يُرسل.
  • الواجهة والتقارير بالإنجليزية والعربية، ومن اليمين إلى اليسار حيث تحتاج العربية ذلك.
  • qa-wrap-bridge، جسر MCP للقراءة فقط، يتيح لوكيل برمجة قراءة الجلسات التي سجلتها.

أين تقصر QA-Wrap

  • لا توجد روابط مشاركة مستضافة. تسلّم التقرير بنفسك، أو ترسله إلى Jira أو أداة تتبع أو ويب هوك.
  • ليست في متجر Chrome الإلكتروني. تُثبَّت في Chrome وEdge من ملف الإصدار المضغوط مع وضع المطور، في نحو 3 دقائق ولمرة واحدة. ومستخدمو Firefox يثبتونها من متجر Firefox Add-ons.
  • يصنعها شخص واحد: نادر الزغول، مهندس أتمتة جودة في عمّان، الأردن.
