QA Wrap records what you do in the page, then explains what broke and why.

  1. Click the QA Wrap icon in the toolbar.
  2. Press Wake up, so QA Wrap is awake in this window.
  3. Name what you are testing. This becomes the report title.
  4. Press Start recording, then use the page normally.
  5. Press Stop. Your report appears right here.

Nothing is uploaded. Everything stays in this browser.

What broke

Each problem is matched to the action that most likely caused it, which is the part a bug report usually leaves out.

Accessibility

Found by axe-core, running locally. Automated checks catch roughly a third of real barriers, so manual review still applies.

Page speed

Core Web Vitals and network timing read from the live page, in the state you put it in. Lighthouse cannot do this: it drives its own page load, which an extension is not allowed to do.

Accessibility audit

Run the whole rule set, or pick the rules that matter for this screen. Below that are the checks no automated tool can make, which are the ones a clean scan hides. Each answer is filed into the session as a tagged note.

What axe cannot check

Roughly half of WCAG is not machine-decidable. Answer these while you have the screen in front of you.

Cookies & storage

Read and change what the page is holding. Values are visible here and never recorded: a session, an export and a ticket carry cookie names and flags only.

Local & session storage

Everything that happened

Clicks, requests and console output on one clock. Click any locator to copy it.
