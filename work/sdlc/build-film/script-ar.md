# QA Wrap 40 s commercial, Arabic cut: captions and voice script

Source of truth: `extension/tools/film/commercial40/composition.template.html` (captions, titles, UI words) and `vo-ar.json` (voice). Windows are the shipped EN film's own caption windows, measured from the MP4.

Rules: no visible tashkeel (tashkeel only in the TTS input below); foreign words glossed in brackets on first use; Western digits; Thmanyah only. Voice: Gemini Kore via OpenRouter, one request per line, one take, no verify, no re-voice. Lines run continuously across caption changes.
